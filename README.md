## ⚡ Điểm nổi bật

- **Kho từ vựng:**
  - **HSK 2.0:** 5.000 từ, HSK 1 đến HSK 6.
  - **HSK 3.0 (bản 2025):** hơn 11.000 từ theo khung 9 cấp (Cấp 7–9 học chung một bộ).
  - **Bộ thủ:** 50 bộ thủ cơ bản và 214 bộ thủ Khang Hy.
  - **Từ vựng theo chủ đề:** Công nghệ thông tin (IT), và các chủ đề gợi ý trên trang chủ.
- **Lặp lại ngắt quãng FSRS** (thư viện `ts-fsrs`): tự xếp lịch ôn, chỉnh được **độ ghi nhớ mong muốn** (80–97%), màn **Ôn hôm nay** gom mọi từ đến hạn.
- **Tự động gắn âm Hán - Việt** cho từ vựng và câu.
- **Âm thanh giọng thật MP3** cho từ và câu ví dụ: HSK 2.0 cấp 1–4 và HSK 3.0 cấp 1–5 (cấp 6 đang bổ sung). Các cấp còn lại tự chuyển sang Web Speech API.
- **Luyện nghe HSK 4:** 12 đề thật (H41001–H41012) với audio gốc, transcript đồng bộ theo câu và giải thích đáp án.
- **Tra cứu nhanh** (`Ctrl/⌘ + K` hoặc `/`) và **Sổ từ** để lưu, ôn từ đã đánh dấu.
- **SPA Router:** hỗ trợ nút Back/Forward của trình duyệt và chia sẻ liên kết trực tiếp (deep link).
- **Giao diện sáng / tối**, nền hoa mai thư pháp, tối ưu riêng cho điện thoại.
- **PWA 100% offline:** Service Worker cache sẵn ứng dụng; dữ liệu bài đọc luôn lấy bản mới khi có mạng. Có banner báo khi có phiên bản mới.

## 🏛️ Kiến trúc

Ứng dụng là một trang tĩnh (`index.html`) chạy trực tiếp trên GitHub Pages, **không cần build khi deploy**. Giao diện được chuyển dần sang **Preact + Signals** theo mô hình *islands*: mỗi island render đúng markup và class CSS cũ, nên giao diện giữ nguyên.

```
index.html                  # App shell (header, tabs, dock, mobile nav)
sw.js                       # Service Worker (PWA offline, cache theo APP_VERSION)
VERSION                     # Nguồn phiên bản duy nhất
│
├── src/islands/            # Mã nguồn Preact islands
│   ├── main.jsx            # Điểm vào, mount toàn bộ islands
│   ├── AppBootstrap.js     # Gắn sự kiện cho markup tĩnh
│   ├── SpaRouter.js        # Router Back/Forward & deep link
│   ├── SrsEngine.js        # Lịch ôn FSRS (ts-fsrs)
│   ├── StorageEngine.js    # Lưu tiến trình trong localStorage
│   ├── SpeechAudio.js      # Audio MP3 dựng sẵn + fallback Web Speech API
│   ├── FlashcardStudy.jsx  # Thẻ học & chấm điểm
│   ├── GradedReading.jsx   # Bài đọc phân cấp & trình đọc truyện tranh
│   ├── ListeningPractice.jsx, ReadingAnalysis.jsx, FastReview.jsx, ...
│   └── ...                 # Game, bộ thủ, dashboard, tra cứu, sao lưu
│
├── assets/
│   ├── js/preact/islands.js   # Bundle islands đã build (được commit)
│   ├── css/                   # CSS theo module
│   ├── flashcards.css         # CSS gộp & minify từ assets/css
│   ├── audio/exams/           # Audio đề nghe HSK 4
│   └── images/                # Ảnh minh họa, bìa sách, trang truyện, screenshots
│
├── database/               # Dữ liệu JSON
│   ├── vocabs/             # HSK 2.0, HSK 3.0 (hsk3_0/), chủ đề, ngân hàng game
│   ├── readings/           # Bài đọc HSK 1–9, Vạn vật thú vị, manga/peppercarrot
│   ├── listening/          # 12 đề nghe HSK 4
│   ├── reading/, grammar/, sentence/, radicals/, illustrations/
│   └── prebuilt_audio/     # MP3 từ & câu ví dụ theo cấp
│
├── tools/                  # Script Python dựng dữ liệu, audio, OCR, bump version
└── tests/                  # Kiểm thử Python (pytest) & Node
```

## 💻 Chạy cục bộ

```bash
# Cách 1: Vite dev server (http://localhost:3000)
npm install
npm run dev

# Cách 2: không cần Node.js (http://localhost:8000)
python3 -m http.server 8000
```

### Build
```bash
npm run build:islands   # src/islands -> assets/js/preact/islands.js (commit file này)
npm run build:css       # assets/css -> assets/flashcards.css
npm run build           # chạy cả hai
```

### Kiểm thử
```bash
npm test                # kiểm thử Node (pinyin của Ôn nhanh)
python3 -m pytest tests # kiểm thử bố cục & dữ liệu
```

### Phát hành phiên bản
`VERSION` là nguồn duy nhất. Script đồng bộ số phiên bản vào `package.json`, `sw.js`, cache-buster `?v=` và badge footer:
```bash
python3 tools/bump_version.py patch   # hoặc minor / major / X.Y.Z
```

### Nhập / cập nhật truyện tranh Pepper&Carrot
```bash
python3 -m venv .venv-manga
.venv-manga/bin/pip install jieba opencc-python-reimplemented pypinyin Pillow
.venv-manga/bin/python tools/import_peppercarrot.py          # tất cả các tập
.venv-manga/bin/python tools/import_peppercarrot.py 40 41    # chỉ một vài tập
```
Script tải ảnh bản tiếng Trung và file SVG nguồn (cn + vi) từ peppercarrot.com, lấy chữ thoại và tọa độ chính xác từ SVG (không cần OCR), dựng lớp tra từ và ghi manifest. Xem [tools/import_peppercarrot.py](tools/import_peppercarrot.py).
